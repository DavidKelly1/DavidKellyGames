My Vibe

A productivity helper game inspired by the YouTube Lofi Girl, set yourself a task and get rewards. Customize your house, chat with people and listen to your favourite songs.

PC Hobby Project

My work

My Vibe is a solo hobby project I built entirely from scratch. It gave me the freedom to explore areas I don't always get to touch professionally, from 3D modelling and rigging in Blender to designing UI in Figma and integrating online systems.

Some of my learnings included:

  • Created all 3D models in Blender, mastered single-texture efficiency, and rigged characters for animation.
  • Learned how to smoothly transition between animations using humanoid retargeting with Mixamo.
  • Built an online chat functionality utilising the Vivox API.
  • Designed all UI elements in Figma, my first time using the tool.
  • Implemented Unity NavMesh for character movement and customised walkable zones, making sure newly placed furniture recalculates the moveable area.
